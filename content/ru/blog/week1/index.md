На этой неделе я работала над созданием личного академического сайта.

Я использовала генератор статических сайтов Hugo с темой HugoBlox Academic CV. Основные задачи:
- Установка и настройка Hugo
- Создание репозитория на GitHub
- Деплой на GitHub Pages через GitHub Actions
- Настройка темы и личных данных

Это был отличный опыт работы со статическими генераторами сайтов и CI/CD.
