При разработке современных сайтов критически важно использовать правильные инструменты автоматизации.

### Что такое Git?
Git — это система контроля версий для сохранения истории изменений кода.

### Что такое CI/CD?
CI/CD — это практика автоматизации сборки и развертывания. Каждый раз, когда мы делаем `git push`, хостинг автоматически собирает наш сайт Hugo и публикует его в сеть.
